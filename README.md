# 🎂 Birthday Countdown Timer

A simple and interactive **Birthday Countdown Timer** built using HTML, CSS, and JavaScript.

This project displays the remaining time until **12 September 2027** and updates the countdown automatically every second.

## ✨ Features

- 🎂 Countdown to a specific birthday
- 📅 Target date: **12 September 2027**
- ⏱️ Displays remaining days, hours, minutes, and seconds
- 🔄 Automatically updates every second
- 🎨 HTML and CSS combined in a single file
- 💻 Beginner-friendly JavaScript project
- 📱 Simple and responsive design

## 🛠️ Technologies Used

- **HTML** – Page structure
- **CSS** – Styling and layout
- **JavaScript** – Countdown functionality

## 📂 Project Structure

The project contains:

- `index.html` – Contains the HTML structure and CSS styling
- `script.js` – Contains the JavaScript countdown functionality
- `README.md` – Project documentation

## 🧠 What I Learned

While building this project, I practiced:

- Working with JavaScript Date objects
- Calculating the difference between two dates
- Converting milliseconds into days, hours, minutes, and seconds
- Using `setInterval()` for real-time updates
- DOM manipulation
- Combining HTML and CSS in one file
- Connecting JavaScript with HTML elements

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. The countdown will start automatically.
